# Hotel Booking Cancellation Prediction Using Machine Learning

## Project Overview

This project aims to predict whether a hotel booking will be cancelled using machine learning techniques. The analysis focuses on identifying the key factors influencing booking cancellations and building predictive models to help hotels reduce revenue loss.

## Dataset

The dataset contains hotel booking information such as:

* Hotel Type
* Lead Time
* Market Segment
* Customer Type
* Previous Cancellations
* Average Daily Rate (ADR)
* Special Requests

### Target Variable

**is_canceled**

* 0 = Not Cancelled
* 1 = Cancelled

## Technologies Used

* Python

* NumPy
* Matplotlib

* XGBoost

## Machine Learning Models

* Logistic Regression
* Random Forest Classifier
* XGBoost Classifier

## Project Workflow

1. Data Cleaning
2. Missing Value Handling
3. Exploratory Data Analysis

6. Model Training
7. Model Evaluation
8. Feature Importance Analysis

## Evaluation Metrics

* Accuracy Score
* Precision
* Recall
* F1-Score
* Confusion Matrix

## Key Findings

* Lead Time is a major factor influencing booking cancellations.
* Previous cancellations increase future cancellation probability.
* Special requests reduce cancellation likelihood.
* Market segment significantly affects booking behavior.
* Random Forest and XGBoost achieved the best performance.

## Conclusion

Machine learning can effectively identify high-risk bookings and help hotels take proactive measures to reduce cancellations.
